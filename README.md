# Python Phonebook Project

A simple phonebook application written in Python.

## Features

- Add new contacts
- Delete contacts
- Edit contact information
- Search contacts by name or phone number
- Display all contacts
- Sort contacts alphabetically
- Store phone numbers, email addresses, and home addresses
- Save contact information in a local file
- Load saved contacts when the program starts

## Technologies

- Python 3
- Python IDLE

## How to Run

1. Download `phonebook.py`.
2. Open the file using Python IDLE.
3. Press F5 to run the program.

## Note

Contact information is stored locally in `phonebook.txt`. Do not upload personal contact information to a public repository.
